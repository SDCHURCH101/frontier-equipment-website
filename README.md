# Frontier Equipment Company — Website

Static marketing site for Frontier Equipment Company (North Slope / Prudhoe Bay
leasing of shop, pad, and man-camp space).

Plain HTML/CSS/JS — no build step. `index.html` is the entry point; assets live
under `assets/`.

## Deploy
Static host. Publish directory = repository root (the folder containing
`index.html`). No build command needed.
